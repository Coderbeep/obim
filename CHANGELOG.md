# Changelog

## Unreleased

## 0.9.0-beta-1

First public beta of the rebuilt obim desktop application.

### Added

- Local-first workspaces with portable Markdown notes, PDFs, tasks, tabs, and split panes.
- Markdown editing with inline previews, tables, equations, checklists, and document navigation.
- A PDF reader with search, outlines, linked selections, and article imports from DOI and arXiv references.
- Task boards, workspace search, bookmarks, and local Git history with optional remote synchronization.
- Automatic updates to Markdown note links when workspace files are renamed or moved.
- Paste a URL over selected editor text to turn that text into a Markdown link.

### Fixed

- External file drops remain available until their native drop handlers complete.
- File Explorer rename fields fill the available row width instead of clipping longer filenames.
- Selected text in code blocks remains visible above the code block background.
- Workspace search opens at the intended position.

### Changed

- Published cross-platform beta installers for macOS Apple Silicon and Intel, Windows x64, and Linux x64.
